# 📟 Morse Code Translator

**Morse Code Translator** is a simple and intuitive web tool that allows users to convert text into Morse code and decode Morse code back into readable text.

🔗 **Live Demo**: [Try Morse Code Translator here](https://danishinnovates.github.io/Morse-code-translator/)

---

## 🚀 Features

- 🔤 Convert plain text to Morse code
- 🔄 Decode Morse code back to plain text
- 🎯 Easy-to-use interface with instant results
- 💻 Responsive design for desktop and mobile devices

---

## 🧑‍💻 How to Use

1. Go to the [live site](https://danishinnovates.github.io/Morse-code-translator/).
2. Enter the text you want to translate in the input box.
3. Click the “Encode” button to convert text to Morse code.
4. To decode Morse code, enter Morse signals and click the “Decode” button.
5. Copy the output as needed.
